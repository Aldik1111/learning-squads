# Обновление интерфейса — 15.11.2026

Основание: прямое поручение владельца адаптировать переданный frontend Learning Squads. Задача #25. Источник оформления — локальный Vite/React-макет `learning-squads/frontend`; он не заменяет работающий Next.js и его серверные контракты.

Перенесены Plus Jakarta Sans, навигация с иконками и отдельным профилем, главная с белыми карточками курсов и терракотовыми акцентами, тёмная инструкция тестировщика, фильтры каталога, структура урока с навигацией по разделам, состояния quiz, карточка профиля, оформление тарифов и общие формы/панели. Шрифт обслуживается приложением через next/font; браузер пользователя не обращается за ним к Google Fonts. Новых npm-зависимостей нет.

Сохранены серверные попытки/результаты, изолированный Python runner, гостевые аккаунты Supabase, автоматические группы Python/AI до четырёх участников, расписание/переназначение, закрытый чат/прогресс, отдельный Spanish и настоящие Google Meet-ссылки. Схема БД и API не меняются.

Из макета не перенесены вымышленные XP/streaks, автоматический зачёт модулей, демонстрационные группы/партнёры, localStorage вместо backend, ручные Meet/Jitsi URL, скрытая автоподстановка собеседника, очистка всей localStorage, неработающая форма обратной связи и обещания несуществующих платных функций. $19/месяц остаётся гипотезой; все функции текущего MVP бесплатны. Эти различия нужны для соблюдения ранее принятых правил, а не являются новым сокращением продукта.

Локально с настоящим Supabase проверены: главная на 1440/390/320px, переход к инструкции и реальные ссылки уроков; фильтры каталога; quiz3/4 с сохранением и восстановлением четырёх ответов; сохранение кода в редакторе при переходах по разделам; формы профиля с save/reload; демотариф, фокус Cancel, Escape, выбор/очистка и сброс после reload. На проверенных экранах нет горизонтального переполнения. TypeScript и ESLint прошли. Python runtime и внешняя медиасвязь этим UI-прогоном повторно не проверялись.

Точный опубликованный SHA/URL и проверка сборки фиксируются в docs/demo.md после завершения интеграции. Исторический пакет презентации не считается автоматически пересобранным под новый выпуск.
