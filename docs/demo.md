# Приёмка и демонстрация
Статус всех сценариев: NOT RUN. A обновляет фактический SHA, URL, дату, результат и ограничения после проверки.

## Учебный сценарий
Гость → профиль → направление → материал → тест → объяснение результата → обновление → сохранённый прогресс.
Для Python: корректный код, неверный результат, синтаксическая ошибка, остановка бесконечного цикла.

## Языковой сценарий
Два независимых браузерных контекста. Первый: Spanish основной + готов к общению. Второй: запрос практики. Первый видит приглашение и принимает. Оба открывают настоящую Meet-ссылку, отметки перехода сохраняются.
Проверить отсутствие кандидатов, отказ, истечение срока, отмену и чужое приглашение.

## Командный сценарий
Создать команду, вступить другими аккаунтами, пригласить нескольких участников, проверить независимые ответы и доступ к встрече.
Повторные запросы не создают дублей. Выход не удаляет чужой прогресс.
Время с перехода не выдаётся за доказанное посещение. Автоматического зачёта по неутверждённому правилу нет.

## Сдача
- Сайт работает без обязательного входа в приложение.
- Репозиторий открыт без запроса доступа.
- PDF ≤10 слайдов; описание реально готовых функций.
- Бизнес-гипотезы, подтверждённые факты и тестовые данные различимы.
- Презентация: проблема/пользователь, решение, демонстрация, ценность/удержание, отличие, бизнес-модель и экономика как гипотезы, следующий шаг.
- Проверить доступ к Meet отдельно; гостевой доступ приложения не гарантирует гостевой доступ внешней конференции.
