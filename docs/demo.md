## Сценарии для повторения на новом deployment v0.4

Это инструкция для повторения. Фактически проверенная часть опубликованного выпуска перечислена в начале документа; шаги реального двустороннего Meet не считаются выполненными. Использовать два отдельных профиля/независимых контекста браузера; две обычные вкладки одного профиля используют одного гостя.

### Учебный сценарий
Гость → профиль → направление → материал → тест → объяснение результата → обновление → сохранённый прогресс.
Для Python: корректный код, неверный результат, синтаксическая ошибка, остановка бесконечного цикла.

### Языковой сценарий
Первый: Spanish основной + готов к общению. Второй: запрос практики. Первый видит приглашение и принимает. При настроенном Google оба открывают подготовленную приложением настоящую Meet-ссылку, отметки перехода сохраняются. Без провайдера должна отображаться недоступная ссылка; такой результат не подтверждает видеосвязь.
Проверить отсутствие кандидатов, отказ, истечение срока, отмену и чужое приглашение.

### Групповой сценарий Python/AI
Сохранить совместимые недельные окна и часовой пояс двух гостей; записать обоих в один курс. Проверить автоматическую общую группу, её чат, отображение результата участника и календарь. При настроенном Google проверить подготовленную настоящую ссылку. Изменить расписание одного участника на несовместимое: проверить новую группу, недоступность старого чата, сохранение личного результата и отмену прежней встречи. Повтор записи не создаёт вторую группу того же курса. Spanish не должен предлагать групповую запись.
