Порядок действий для репетиции:

1. **10 с:** открыть `/dashboard`, выбрать Python. «Здесь есть материал и конкретная задача: посчитать выполненные привычки».
2. **20 с:** в упражнении запустить `def count_completed(habits): return len(habits)` с переносом строки и отступом перед `return`. «Мы специально считаем все привычки. Три примера проходят, три обнаруживают ошибку».
3. **10 с:** заменить `len` на `sum`, повторить запуск. «Теперь шесть проверок проходят. Это учебная самопроверка, не сертификат».
4. **10 с:** показать подтверждение сохранения и обновить страницу. Этот шаг прошёл и на указанном публичном URL. «Результат восстановился у того же гостевого профиля».

Первый запуск Python загружает публичный runtime. Перед выходом на сцену проверить соединение и один раз выполнить упражнение на демонстрационном браузере. Это прогрев реального runtime, а не подмена результата. Если загрузка не удалась, честно назвать ошибку и продолжить с PDF, не выдавая скриншот за текущее исполнение.

В более раннем локальном прогоне с облачной БД первая загрузка runtime завершилась ошибкой CDN; повторный Run checks выполнил Python, сохранил результат и прошёл reload. На опубликованном preview Python прошёл с первой попытки без повторной загрузки. Доступность CDN на защите всё равно зависит от внешнего сервиса и соединения.

## Подготовка к двум минутам вопросов

- **Кто подтверждает, что человек носитель?** Никто: основной язык указан самим пользователем. Проверенную квалификацию мы не обещаем.
- **Как работает аккаунт без регистрации?** Supabase создаёт анонимную сессию, сохранённую в профиле браузера. Удаление данных браузера может лишить доступа к этому прогрессу; восстановления пока нет.
- **Что если собеседника нет?** Материал и проверки остаются доступны. Пользователь может вернуться к поиску позже или договориться с командой.
- **Почему не написать всё в AI-чате?** Мы проверяем ценность связанного учебного пути и совместной практики. В MVP направление AI обучает формулировать запросы и проверять ответы; подключённый AI-провайдер ему не нужен.
- **Где доказательство удержания и готовности платить?** Пока его нет. Слайд показывает измеряемую гипотезу и план пилота.
- **Откуда сто миллионов ARR?** Это ориентир задания и арифметический сценарий при явно заданной цене. Исследование рынка и прогноз продаж не проводились.
- **Можно подделать Python-результат?** Это клиентская учебная самопроверка, поэтому сервер хранит её как недоверенный practice record. Обычный тест оценивает сервер. Сертификацию на этом основании мы не выдаём.
- **Что означает зелёная проверка в GitHub?** Только конкретные прошедшие проверки соответствующего SHA. Она не доказывает, что эта версия уже выложена и принята.
